# ♻️ Smart Waste Segregation API (Garbage Classification)

An image classification system that identifies the type of waste in a photo (e.g. plastic, metal, paper, organic, etc.) and returns disposal guidance — built with **FastAPI** for the backend API and **TensorFlow** for the classification model, with a simple **frontend** for uploading images.

## 🚀 Features

- **Image classification** — upload a photo and get back the predicted waste category with a confidence score
- **Disposal guidance** — each prediction includes whether the item is recyclable, the recommended disposal method, and practical tips
- **REST API** built with FastAPI, including CORS support for frontend integration
- **Health check endpoint** for monitoring/uptime checks
- **Dockerized** for easy deployment
- Detailed request/response logging for debugging predictions

## 🗂️ Project Structure

```

├── frontend/         # Client-side app for uploading & viewing predictions
├── model/           # Trained model files

│   └── inference.py   # Model prediction + disposal info lookup

├── test_api.py       # API tests
```

## 🛠️ Tech Stack

- **Backend:** FastAPI, Uvicorn
- **ML/Inference:** TensorFlow (CPU), NumPy, Pillow
- **Containerization:** Docker (Python 3.11-slim base image)

## 📦 Installation

### Prerequisites
- Python 3.11+
- pip

### Setup

```bash
# Clone the repository
git clone https://github.com/Pankajkr-1/garbage-Classification.git
cd garbage-Classification

# Create a virtual environment (recommended)
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

## ▶️ Running the API

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

The API will be available at `http://localhost:8000`.

Interactive API docs (Swagger UI) are auto-generated by FastAPI at:
```
http://localhost:8000/docs
```

## 🐳 Running with Docker

```bash
# Build the image
docker build -t garbage-classification .

# Run the container
docker run -p 8000:8000 garbage-classification
```

## 📡 API Endpoints

### `POST /api/classify`
Classifies an uploaded image of waste.

**Request:** `multipart/form-data` with a `file` field (accepts `image/jpeg`, `image/png`, `image/webp`, `image/jpg`)

**Example (cURL):**
```bash
curl -X POST "http://localhost:8000/api/classify" \
  -F "file=@test_image.jpg"
```

**Example Response:**
```json
{
  "category": "plastic",
  "display_name": "Plastic",
  "confidence": 0.943,
  "recyclable": true,
  "disposal_method": "Rinse and place in the recycling bin",
  "tips": ["Remove caps before recycling", "Flatten to save space"],
  "all_scores": { "plastic": 0.943, "paper": 0.021, "metal": 0.015 },
  "processing_time_ms": 128.4
}
```

### `GET /api/health`
Simple health check.

**Response:**
```json
{ "status": "ok" }
```
